2. Memory Detection Function
This is the key AI-powered component that detects when users want to store information:

// Detects phrases like "Remember that..." or "My favorite restaurant is..."
function detectMemoryRequest(message) {
  const rememberPatterns = [
    /remember that (.+)/i,
    /please remember (.+)/i,
    /my favorite (\w+(?:\s+\w+)*) is (.+)/i,
    /(.+) is the best (.+?) in (.+)/i,
    /(.+) is my (.+)/i
  ];
  for (const pattern of rememberPatterns) {
    const match = message.match(pattern);
    if (match) {
      // Extract key-value pairs from the statement
      const { key, value } = extractKeyValueFromStatement(match[1]);
      return {
        isMemoryRequest: true,
        memoryKey: key,
        memoryValue: value,
        originalStatement: match[1]
      };
    }
  }
  return { isMemoryRequest: false };
}

4. Chat Integration
Modify your chat function to:

// In chat endpoint
if (agent.isPersonal) {
  // Check for memory requests
  const memoryRequest = detectMemoryRequest(message);
  if (memoryRequest.isMemoryRequest) {
    // Store or update memory
    await storage.createPersonalMemory({
      userId,
      agentId: agent.id,
      memoryKey: memoryRequest.memoryKey,
      memoryValue: memoryRequest.memoryValue,
      originalStatement: memoryRequest.originalStatement
    });
  }
  // Add memories to system prompt
  const memories = await storage.getPersonalMemories(userId, agent.id);
  const memoryContext = formatMemoriesForPrompt(memories);
  systemPrompt += memoryContext;
}

6. Memory Context Formatting
function formatMemoriesForPrompt(memories) {
  if (!memories.length) return "";
  
  const memoryText = memories.map(m => 
    `${m.memoryKey}: ${m.memoryValue}`
  ).join('\n');
  
  return `\n\nPersonal Information to Remember:\n${memoryText}\n\nReference this information when relevant to provide personalized responses.`;
}
The core concept is using AI to detect when users share personal information, automatically storing it in a structured way, and including it in future conversations for personalized responses. This creates a truly personal AI assistant that remembers things about the user across conversations.
