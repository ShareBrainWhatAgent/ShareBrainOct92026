# TTS-Optimized Language Learning Guide with Visual Vocabulary

## 📋 Lesson Display Format

Each lesson now appears in two sections:

1. **Vocabulary with translations** – a line-by-line list of each word and its English meaning (e.g., "hola - hello") for visual reference. No numbers are used.
2. **Native practice section** – the words and example sentences only in the target language. This lower section is what the text-to-speech system reads aloud.

This format keeps translations on screen while ensuring audio playback contains only the native language content.

### 📚 Best Practices for Visual + TTS Learning

**Step-by-Step Workflow:**
1. Ask: "Give me 20 basic [language] words with images"
2. Use TTS to hear pronunciation of the word list
3. Generate images for each word using the provided descriptions
4. Study the images while listening to TTS pronunciation
5. Practice recall: look at image → say word → check with TTS

**Effective Learning Combinations:**
- **Visual + Audio**: See the image while hearing the word
- **Spaced Repetition**: Review the same image-word pairs daily
- **Context Building**: Ask for thematic groups ("kitchen items", "family members")
